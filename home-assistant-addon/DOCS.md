# AppleLook

Copies your Outlook work calendar into an iCloud calendar you can share with family,
every 15 minutes.

Open **AppleLook** in the sidebar and fill in:

1. Your Outlook calendar's ICS link (Outlook on the web: Settings → Calendar → Shared
   calendars → Publish a calendar).
2. Your Apple ID and an app-specific password from account.apple.com.
3. The iCloud calendar to copy into.
4. What others see: a label, meeting titles, locations, Tentative and Free meetings.

Then **Save and Sync**. Settings live in this add-on's storage and survive updates.

AppleLook only changes events it added itself. If it replaces outlook-busy-bridge in
the same calendar, tick **Advanced → Take over events from outlook-busy-bridge** so it
manages those events instead of adding copies.
